# Main Office: Speak window

A single static page that Main Office (a school main-office tool) opens as a small pop-up so speech typing works where the Main Office page itself can't use the microphone; the words are transcribed by the browser's own built-in speech service (in Chrome, that service is Google's), shown for checking, and sent back only to the Main Office page that opened the window, after which the window closes. The page stores nothing (no cookies, no local storage, no data, no analytics) and makes no network requests of its own.
